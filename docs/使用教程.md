# 使用教程

从装好到能投屏，按顺序走一遍即可。概念和排查见[常见问题](常见问题.md)。

## 第 0 步：手机端准备

1. 打开手机的「设置 → 关于手机」，连续点击「版本号」7 次，直到提示已进入开发者模式
2. 回到「设置 → 系统 → 开发者选项」，打开 **USB 调试**
3. 如果要用无线调试（Android 11+），再打开 **无线调试**

## 第 1 步：连接手机

程序支持四种连接方式，按你的情况挑一种即可。

### 方式 A：USB 数据线（最省事）

用数据线把手机连到电脑。程序会自动识别，状态栏（界面左下角）变成：

```
● 已连接 <手机型号>（USB 有线）
```

首次连接时手机会弹出「**允许 USB 调试吗？**」，勾选「一律允许」后点允许即可。

### 方式 B：扫码连接（推荐给无线调试）

点左侧边栏「设置」分组里的「设备与连接」→ 「添加设备」区域 → 点
「扫码连接（推荐）」，界面会出现一个二维码：

1. 手机上进入「设置 → 系统 → 开发者选项 → 无线调试」
2. 点「**使用二维码配对设备**」
3. 用手机扫描电脑上出现的二维码

扫描成功后状态栏提示「扫码连接成功：<地址>」。想中途取消，再点一次按钮
（此时按钮已变成「停止扫码配对」）。

### 方式 C：扫描 / 深度搜索

在同一「添加设备」区域：

| 按钮 | 适用场景 | 说明 |
| --- | --- | --- |
| 扫描局域网 | 手机与电脑在同一网段，且已用 5555 端口开过无线调试 | 快，几秒出结果 |
| 深度搜索 | 跨网段、或 Android 11+ 的随机端口 | 局域网 + mDNS + 端口扫描（30000~50000），约 6 秒先出结果，最全但稍慢。搜索期间按钮会变成「停止搜索」，随时可以停，已发现的结果保留 |

搜索结果是一行行的设备，**点任意一行即可直接连接**，该行的状态会依次变化：

```
点一下连接  →  连接中…  →  等待手机授权…  →  已连接
                                        ↘  连接失败
```

### 方式 D：其它方式（USB 转无线 / 按地址 / 配对码）

在「添加设备」下方有一条默认收起的折叠项「**其它方式：USB / 按地址 / 配对码**」，
点开展开后有三个入口：

- **USB 一键转无线**：手机已用数据线连上（且已允许 USB 调试）时，点右侧「转无线」，
  程序会自动切到 5555 无线模式并连上，之后就能拔线了
- **按地址连接**：手动填 IP 地址与端口（默认 5555），点「连接」
- **首次配对**：在手机上点「无线调试 → 使用配对码配对设备」，把手机显示的**配对端口**
  和**配对码**填进来，点「配对」；成功后提示「配对成功：现在点「连接」或到「最近连接」里连它」

> 无线调试的配对码和调试端口是**两个不同的端口**：配对端口只在配对时用一次，
> 配对完要用「无线调试」页面上显示的地址去连接。

## 第 2 步：投屏

手机连上之后，左侧边栏的「设备」分组里出现设备入口——**一台设备就是一个主页**，
点哪台就切到哪台的应用页（多台设备各占一个）。一台设备都没有时，界面会直接停在
「设备与连接」页，引导你先连上一台。

| 想投什么 | 怎么做 | 效果 |
| --- | --- | --- |
| **镜像桌面** | 点主页第一行的「镜像桌面」 | 把手机真实桌面投到电脑窗口，手机屏幕上的内容原样显示 |
| **镜像应用** | 在「快捷启动」或「全部应用」里**点一下应用卡片** | 单独为这个应用开一块虚拟屏来投，不影响手机本身在干什么 |

「镜像应用」是这个项目比较特别的一点：它给目标应用单独开一块虚拟屏，
你可以一边在电脑上操作某个 App，一边正常使用手机，两边互不干扰。
这样开出来的窗口，**标题栏用的是目标应用的名字和图标**（而不是一律显示 scrcpy），
同时开几个也一眼能分清哪个是哪个。

启动过程会在状态栏提示（如「正在启动镜像桌面…」）；如果失败，会直接显示 scrcpy
返回的原始错误信息，方便定位原因。

## 第 3 步：把常用应用放上「快捷启动」

首页顶部的「快捷启动」区是你最常用的几个应用，点一下就能启动并投屏：

1. 把鼠标移到「全部应用」里任意一张应用卡片上
2. 卡片右上角出现「**＋**」，点它，该应用就加进快捷启动了
3. 快捷启动里的卡片右上角是「**×**」，点它移出

快捷启动是**按设备各存一份**的——手机和平板可以有不同的常用列表。每台**最多 8 个**
（标题右侧的「N / 8 个」就是当前用量），加满后要再加就得先移出一个。

「全部应用」是一个可折叠抽屉：

| 控件 | 说明 |
| --- | --- |
| 标题栏「全部应用」 | 点标题栏任意位置折叠 / 展开；折叠状态会被记住 |
| 「↻ 刷新」 | 重新扫描当前设备的应用列表（扫描结果按设备缓存） |
| 搜索框 | 支持中文、**拼音和首字母**（如 `wx`、`weixin` 都能搜到微信）；按 Esc 清空 |
| 应用卡片 | 点卡片 = 启动该应用并投屏；点右上角 ＋/× = 加入 / 移出快捷启动 |

## 第 4 步：按需调整设置

点左侧边栏「设置」分组里的任一项进入设置页（设置页显示在右侧区域，没有自己的标题行和关闭
按钮：点侧边栏顶部的应用名或任意设备入口即可回到主页；侧边栏始终可见，可以随时在几个标签间
切换，当前标签会高亮）。设置分四个标签。

### 设备与连接

- **已连接设备**：列出当前在线设备，可在此断开
- **掉线自动重连**：默认开启。无线掉线（手机熄屏、路由器休眠）后自动重连，
  间隔 6 → 12 → 24 → 60 秒逐次拉长，最多 10 次；主动点「断开」的设备不会被重连
- **最近连接**：记住最近 5 台连接过的设备，点一下即可重连
- **添加设备**：上面[第 1 步](#第-1-步连接手机)讲过的扫码 / 扫描 / 深度搜索入口都在这里
- **锁屏解锁**：手机锁着时投出来的只有锁屏画面。在这里**按手机分别**填好锁屏密码再点
  「保存」（点「清除」则不再为这台手机提供解锁），之后点主页第一行的「解锁」，
  程序会在后台点亮屏幕、静默上滑并输入密码。密码按手机的**硬件序列号**归档，
  同一台手机 USB 与无线通用。只支持数字 PIN / 字母数字密码，图案锁、指纹、人脸无法自动解锁
- **图标**：应用图标默认取自随包内置的素材库，抓不到就显示首字母。设备**第一次连上**程序就会在
  后台自动从手机取一次图标（手机侧推一个 dex 上去用 `app_process` 跑一遍，不装 App、不要权限、
  也不弹界面，全程不用你操作，设置里也没有开关）；取回的图标**优先于**内置素材库显示，形状也
  跟素材库一致（圆角方形），并连同「这台设备取过了」一起存进数据流，之后连上、断开重连都直接
  用存下来的那份，不再重取——想立刻重取一次，在首页点「刷新」。取图程序换了渲染方式时（比如
  某一版给图标补了圆角），程序会把该设备上的记录作废，下次连上自动重取一份，不用手动刷新。
  万一取图失败（比如手机上装了拦 `app_process` 的安全软件），这一步会跳过，图标继续用内置
  素材库，原因记在扫描日志里

### 画面与声音

| 区块 | 设置项 | 说明 |
| --- | --- | --- |
| 画面 | 最大帧率、码率 (Mbps)、视频编码、最大尺寸 | 对「镜像应用」和「镜像桌面」**都生效**；最大尺寸填 0 表示原始分辨率；编码可选 自动 / H.264（兼容性最好）/ H.265（同画质更省带宽） |
| 虚拟屏（仅「镜像应用」） | 宽、高、UI 放大倍数、分辨率预设 | 启动快捷启动里的应用时按这个分辨率新开虚拟屏，**不影响手机本身的设置**；「镜像桌面」显示的是手机真实画面，与此无关。UI 放大倍数填 1.0 时与电脑 DPI 一致 |
| 声音 | 声音输出 | 可选「手机和电脑都播放」/「仅手机播放」/「仅电脑播放」。选「仅电脑播放」时，投屏期间会把手机媒体音量调到最大（scrcpy 抓的就是手机输出的那路声音，音量压着电脑这边就没声），**关掉投屏窗口后自动还原**成原来的音量 |

分辨率预设可以「保存当前」把当前宽高存成一套预设，之后从下拉里选，或「删除所选」删掉。

改完设置**重新投屏一次**即可生效。

### 常规

- **浅色主题**：默认浅色，关掉这个开关就换成深色。主窗口标题栏跟着换成同色，并且
  不显示图标与标题文字，看起来接近无边框（拖动、最小化、关闭都还是系统原生的，照常可用）。
  主题存在配置里，下次打开直接就是上次选的那套，不会先亮一下再变
- **关闭主界面时缩小到托盘**：开启后点关闭不会退出应用，而是收进系统托盘继续后台待命
- **投屏窗口置顶**：投屏窗口始终压在其他窗口上面，适合一边看着手机画面一边在电脑上干别的；
  对「镜像应用」和「镜像桌面」都生效。投屏窗口用的是**系统原生标题栏**（所以拖边缩放、
  双击最大化、贴边、系统菜单都照常可用），快投在上面补了三样东西：把它染成深色（投屏窗口
  固定深色，不跟随主界面主题）、把图标换成目标应用自己的图标，并在系统按钮左边叠上一个
  置顶按钮——点它就能当场切换置顶，不用回设置页（两边的开关是同一份配置，改哪边都一样）。
  窗口位置会被记住，下次投屏还开在你上次挪到的地方（换过显示器或改过分辨率后，旧位置已经
  在屏幕外时会重新挑一个）
- **开机自启动**：开机后在后台静默启动（只驻托盘、不弹主界面）；开启时会自动勾上「缩小到托盘」

### 诊断

换电脑后遇到「连得上 adb 却扫不出应用 / 投不出画面」时来这里：

| 按钮 | 作用 |
| --- | --- |
| 环境自检 | 快速检查运行环境（adb / scrcpy / 存储位置等） |
| 完整诊断 | 更全面的检查，包含更深层的探测 |
| 保存诊断报告 | 弹出「另存为」对话框，**由你自己选保存位置**（取消则只在界面里显示结果） |
| 导出日志 | 导出 scrcpy 启动日志与扫描日志 |

诊断结果会显示在按钮下方的文本框里。设置页底部显示当前版本号（如「快投 v1.8.1」）。

## 第 5 步：托盘常驻与开机自启

开启「关闭主界面时缩小到托盘」后，点窗口关闭按钮只会把界面收起来，程序继续在托盘待命。
**右键托盘图标**可以看到：

```
打开主界面
─────────────
<手机型号> (<序列号>)  ▸  镜像桌面
                          微信
                          相册
                          …（该设备快捷启动里的应用，最多 12 个）
─────────────
退出应用
```

设备列表是每次弹菜单时实时取的，所以连上 / 掉线都会立刻反映出来。想彻底退出，
用菜单里的「退出应用」，或在关闭托盘功能的情况下直接关窗口。

## 界面速查

| 位置 | 元素 | 作用 |
| --- | --- | --- |
| 左侧边栏 | 「快投」应用名 | 大号标题样式；点一下回主页；右上角箭头把侧边栏折叠成窄条或展开 |
| 左侧边栏 | 设备分组 | **一台设备就是一个主页**，点哪台就切到哪台（各有独立的应用列表和快捷启动）；点右侧的 × 断开该设备。没有设备时这一组不显示，界面停在「设备与连接」页 |
| 左侧边栏 | 设置分组 | 设备与连接 / 画面与声音 / 常规 / 诊断，固定在侧边栏底部，点一下在右侧打开对应标签页，当前标签高亮 |
| 侧边栏折叠时 | 全部标签 | 文字收起，只留图标（设备是手机图标，设置是各自的线框图标） |
| 主页第一行 | 搜索框 | 搜应用，支持拼音 / 首字母 |
| 主页第一行 | 镜像桌面 | 投当前设备的桌面 |
| 主页第一行 | 解锁 / 已解锁 | 当前设备锁着时是可点的「解锁」，已解锁时只是状态显示 |
| 主页第一行 | 关闭物理屏幕 | 只关掉手机的显示，手机**不会**因此被锁定（投屏时省电，随时可再点亮） |
| 首页 | 快捷启动 | 常用应用，点一下启动并投屏；最多 8 个。与第一行一起钉在顶部，不随列表滚动 |
| 首页 | 全部应用 | 可折叠抽屉，含刷新按钮与应用网格；应用列表在这里独立滚动 |
| 左下角 | 状态灯 + 文字 | `已连接` / `等待手机授权：<IP>` / `设备离线：<IP>` / `未连接` |
| 右下角 | 「N 个应用」 | 当前设备扫到的应用数量 |
