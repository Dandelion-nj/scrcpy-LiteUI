设置

已连接设备
掉线自动重连
无线掉线（手机熄屏、路由器休眠）后自动重连，间隔 6→60 秒逐次拉长，最多 10 次；主动点「断开」的设备不会重连。
最近连接
添加设备
手机（Android 11+）：设置 → 开发者选项 → 无线调试 → 使用二维码配对设备，扫描这里出现的二维码。
「扫描」查同网段 5555 端口；「深度搜索」= 局域网 + mDNS + 端口扫描（30000~50000，多线程），能发现跨网段 / 随机端口的设备，较慢但最全。插上数据线会自动用 USB 有线。
其它方式：USB / 按地址 / 配对码
USB 一键转无线
手机用数据线连上电脑（已允许 USB 调试）后点右边按钮：自动切到 5555 无线模式并连上，之后可以拔线。
锁屏解锁
手机锁着时投出来的只有锁屏画面。在这里按手机分别填好锁屏密码并「保存」，之后点顶栏该设备旁边的「解锁」按钮，就会在后台点亮屏幕、静默上滑并输入密码；点「清除」则不再为这台手机提供解锁。密码按手机的硬件序列号归档，同一台手机 USB 与无线通用。只支持数字 PIN / 字母数字密码，图案锁、指纹、人脸无法自动解锁。
画面
这几项对「镜像应用」和「镜像桌面」都生效；改完重新投屏一次即可。
虚拟屏（仅「镜像应用」）
启动快捷启动里的应用时，按下面的分辨率新开一块虚拟屏，不影响手机本身的设置。「镜像桌面」显示的是手机真实画面，与此无关。UI 放大倍数填 1.0 时与电脑 DPI 一致。
声音
窗口与托盘
关闭主界面时缩小到托盘
开启后点关闭不会退出应用，而是收进系统托盘继续在后台待命；右键托盘图标可以重新打开主界面、按设备启动镜像桌面或快捷启动的应用，或退出应用。
启动
开机自启动
开机后在后台静默启动（只驻系统托盘，不弹主界面），右键托盘图标即可投屏。开启时会自动打开上面的「缩小到托盘」。
诊断
换电脑后「连得上 adb 却扫不出应用 / 投不出画面」时点这里。诊断完成后会弹出「另存为」对话框，由你自己选择报告的保存位置（取消则只在这里显示结果）。
