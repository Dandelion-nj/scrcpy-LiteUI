## 投屏窗口多了一条功能栏

投屏窗口的右边缘现在贴着一条细条，**鼠标扫过去就展开**一排按钮，移开约半秒自动收起，平时基本不占画面。

| 按钮 | 作用 |
| --- | --- |
| 置顶 | 把这扇投屏窗口压在最上层 |
| 音量 − / + | 调手机的音量 |
| 强制横屏 | 临时关掉手机的「自动旋转」并转成横屏；再点一次还原成你原来的设置，退出快投时也会自动还原 |
| 返回 / 桌面 / 多任务 | 相当于按手机的返回键、主屏键、最近任务键 |
| 通知栏 / 控制中心 | 展开手机的通知栏 / 快捷设置面板 |

「返回」往下的五个**只在「镜像桌面」里出现**——镜像应用投的是虚拟屏，这几个键打到手机真实界面上没有意义。

功能栏虽然盖在画面上，但只有按钮那几个像素会吃鼠标点击，其余地方鼠标照样穿到画面上，右键返回、拖拽这些都不受影响。

## 设置页的变化

- 新增 **只看不控**：投屏窗口只显示画面，在画面上点击、打字都不再传到手机，防止误触。右侧功能栏的按钮走的是另一条通道，不受它影响
- 新增 **关窗熄屏**：投屏窗口一关就顺手把手机屏幕熄掉（只关显示、不会锁定），省电
- 新增 **鼠标捕获**：把电脑鼠标变成相对模式、光标锁在投屏窗口里，玩游戏时鼠标移动直接落到手机上
- **键盘改成固定直通手机**（电脑键盘直接当手机外设，打字就落在手机上，不依赖手机输入法），不需要设置
- 「投屏窗口置顶」只在功能栏里，设置页不再放这个开关
- 同一板块里的多个功能项之间加了分割线，不再糊成一片

## 窗口位置交给 scrcpy 自己挑

以前会记下你把投屏窗口拖到的位置、下次照搬，还要判断换过显示器之后旧坐标在不在屏幕内。这点小便利换来一整套坐标换算与越界判断，不划算，整块去掉了——现在每次由 scrcpy 自己决定开在哪。

## 修掉几处「出了问题却看不出来」

- **配置没存上会明确报错**。以前写入失败被静默吞掉，界面照旧显示「已保存」，下次打开才发现改动全没了、而且没有任何线索。现在写不进去会直接告诉你
- **配置读坏了会留痕**。以前配置损坏就悄悄回落到默认值，用户只看到「设置莫名其妙全丢了」；现在会在错误日志里记一条
- **音量不会卡在最大档**。选「仅电脑播放」时会把手机音量拉满，以前如果投屏进程没能起来（比如 scrcpy.exe 被杀软拦了），音量就留在最大没人还——现在起不来就还原
- **收进托盘后不再空转**。界面每 3 秒拉一次状态，而那次请求会跑一遍 `adb devices`；窗口缩到托盘（本应用最常见的待机方式）后轮询会停掉
- **断开设备、删除分辨率预设加了二次确认**。设备项的 × 紧挨着「切到这台设备」的点击区，无线设备断掉还要重新配对，值得问一句

## 界面

- 功能栏图标全部重画：改用圆端点、圆连接的细线条，粗细统一
- 键盘可以走完主要操作了：焦点有清晰描边，图标按钮补上了读屏名称，侧边栏项和应用卡片也能用 Tab 走到、回车触发

## 升级说明

单文件便携版，双击即用，无需安装（`scrcpy`、`adb` 已随包附带）。配置写在 exe 的 NTFS 数据流里，**替换 exe 后旧配置不会自动带过来**，首次运行请重新连一次手机、填一下设备与画面设置。

完整说明见 [使用教程](https://github.com/Dandelion-nj/scrcpy-LiteUI/blob/main/docs/使用教程.md)。
